## Calculator (C#)

A console calculator in `Calculator/`. It handles `+ - * / % ^`, parentheses, and unary minus, and applies normal operator precedence.

Requires the [.NET 8 SDK](https://dotnet.microsoft.com/download).

```sh
cd Calculator
dotnet run                    # interactive mode (type 'exit' to quit)
dotnet run -- "2 + 3 * (4 - 1) ^ 2"   # one-shot mode, prints 29
```
